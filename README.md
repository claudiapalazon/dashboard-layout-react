## ✨ Features

- 🎨 **Modern Design**: Clean and professional dashboard interface
- 📱 **Responsive Layout**: Fully responsive design that works on all devices
- ⚡ **Fast Performance**: Built with Vite for lightning-fast development and optimized production builds
- 🎯 **Type-Safe**: Written in TypeScript for better code quality and developer experience
- 🎨 **Styled with Sass**: Modular and maintainable styling with Sass
- 🧭 **Client-Side Routing**: Seamless navigation with React Router
- 📢 **Announcements Section**: Dynamic content management for notifications and updates

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/claudiapalazon/dashboard-layout-react.git

# Navigate to the project directory
cd dashboard-layout-react

# Install dependencies
npm install

# Start the development server
npm start
```

The application will open at `http://localhost:5173`

## 📜 Available Scripts
